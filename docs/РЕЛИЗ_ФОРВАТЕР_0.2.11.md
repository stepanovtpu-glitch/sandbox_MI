# ФОРВАТЕР 0.2.11 — пилотный API метрологических данных

**23.11.2026.** Релиз установлен на корпоративном АРХИМЕДе и внешнем стенде после резервного копирования. PostgreSQL обновлён до схемы 11. Оба контура отвечают как ФОРВАТЕР 0.2.11.

Добавлен версионированный read-only API точного поиска по заводскому номеру для внутренних потребителей: [`API_ФОРВАТЕР_МЕТРОЛОГИЯ_v1.md`](API_ФОРВАТЕР_МЕТРОЛОГИЯ_v1.md). Ответ содержит происхождение последнего снимка, его SHA-256 и свежесть, число кандидатов, плановые сроки на дату среза и сегодня. Поверка помечена как неподтверждённая этим источником; совпадение по номеру не объявляется физической идентичностью СИ. Множественные результаты возвращаются как неоднозначные.

Доступ требует отдельного ключа клиента. В БД хранится только SHA-256; исходный пилотный ключ создан через SSH и остался в `C:/pass/forvater-integration-internal-pilot.json`. Значение ключа не выводилось в журнал и не передавалось по открытому HTTP. На АРХИМЕДе живой запрос через SSH вернул `HTTP 200`, договор `1.0`, источник на 48 312 строк, хеш и одного кандидата. Локально прошли 162 теста backend.

Внешний стенд получил код, но не корпоративную выгрузку и не ключ клиента: 216 МИ, ноль импортов ТОиР, ноль интеграционных клиентов. Подключение реальных систем-потребителей требует согласованных прав, сетевого маршрута с TLS и мастер-идентификатора физического СИ. API не соединяет автоматически ТОиР с записью ФГИС «Аршин».
