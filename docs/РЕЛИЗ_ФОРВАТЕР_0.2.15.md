# ФОРВАТЕР 0.2.15 — бот «Инженерная память»

**23.11.2026.** Образы 0.2.15 установлены на АРХИМЕДе и внешнем стенде после резервного копирования. Корпоративные учётные данные бота находятся только на АРХИМЕДе.

РИТМ 1.17.2 остаётся единственным получателем обновлений Яндекс Мессенджера. В личном чате он передаёт явные команды `/состояние`, `/си`, `/поверка`, `/эксперт` через собственную устойчивую очередь в ФОРВАТЕР. Передача подтверждается после сохранения команды; ФОРВАТЕР обрабатывает её отдельным worker. Смещение polling и постановка в очередь выполняются в одной транзакции РИТМа. Повторная доставка не дублирует команду.

Проверено: бот подтверждён через официальный `self/get`; токен совпадает с установленным в РИТМе; у РИТМа `ga_poll=on`; защищённый маршрут РИТМ → ФОРВАТЕР возвращает 422 для некорректной команды с действительным ключом; оба сервиса и worker работают. Тестовое исходящее сообщение владельцу принято API бота. Пройдены 169 тестов ФОРВАТЕРА и 143 тестов РИТМа. Полный проход через реальное входящее сообщение пользователя и ответ бота ещё не наблюдался.

Ограничения: ФГИС «Аршин» и корпоративная LLM недоступны из серверного контура на момент релиза, поэтому ответы этих веток не подтверждены живыми данными. PDF на основе открытой записи не является официальным свидетельством. Локальный поиск работает по последней выгрузке ИС Метрология; он показывает дату среза и не выдаёт её за факт поверки в ФГИС.
