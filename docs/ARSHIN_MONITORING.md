# Сверка метрологического состояния с ФГИС «Аршин»

## Назначение

ФАРВАТЕР ведёт список конкретных экземпляров СИ и сверяет их заводские номера с публичным интерфейсом ФГИС «Аршин» (`https://fgis.gost.ru/fundmetrology/eapi/vri`). Каталог моделей и записи с примерными серийными номерами не используются как реестр оборудования.

Результат — сохранённая копия общедоступных сведений и ссылка на запись в первичном источнике. Сформированная программой карточка не является свидетельством о поверке.

## Порядок работы

1. Метролог или администратор открывает **Поверки в Аршине → Добавить СИ**.
2. Указывает позиционное обозначение, точный заводской номер; при наличии — номер типа СИ в Госреестре. Поля объекта и источника позволяют связать запись со строкой инвентарной выгрузки.
3. Worker `arshin-checker` выбирает записи, для которых наступил срок проверки. Обычный интервал — 24 часа; цикл worker — 60 секунд.
4. Ответ, полученное время, статус, найденные записи и ошибки фиксируются в PostgreSQL/SQLite. История доступна в карточке СИ.
5. При недоступности интерфейса повтор назначается через 15 минут. Состояние предыдущей поверки не подменяется ошибкой связи.

Проверка выполняется только по HTTPS к `fgis.gost.ru:443`. Для production необходимо разрешить исходящий доступ с контейнера worker до этого адреса. Если соединение не установлено, в системе будет **Источник недоступен**, а не **Запись не найдена**.

## Статусы

| Статус | Значение |
|---|---|
| Действует по записи | В самой поздней найденной записи есть срок, который не истёк на дату ответа. |
| Срок истёк | Срок самой поздней найденной записи уже прошёл. |
| Непригодно | Последняя запись содержит отрицательный результат пригодности. |
| Запись изменена / требует разбора | В записи присутствуют сведения о публикации/изменении; требуется открыть источник и проверить контекст. |
| Запись не найдена | Публичный интерфейс ответил без точного совпадения. Само по себе это не доказывает отсутствие поверки. |
| Источник недоступен | Не получен корректный ответ ФГИС. Состояние поверки по этому запросу неизвестно. |
| Неоднозначный результат | Несколько записей с одинаковой последней датой противоречат друг другу; автоматическое заключение не делается. |
| Нужна проверка | Данных записи недостаточно для однозначного статуса. |

Совпадение заводского номера сравнивается точно после Unicode-нормализации, без удаления внутренних пробелов и знаков. При заданном номере типа он также участвует в фильтрации.

## Роли и API

- Чтение списка и истории: право `metrology:read`.
- Добавление, изменение и запуск ручной проверки: `metrology:manage` (метролог, администратор).
- `GET /api/metrology/arshin/assets`
- `POST /api/metrology/arshin/assets`
- `PATCH /api/metrology/arshin/assets/{asset_id}`
- `POST /api/metrology/arshin/assets/{asset_id}/check`
- `GET /api/metrology/arshin/assets/{asset_id}/history`

## Сопровождение

В production Compose worker называется `arshin-checker`. Он использует базу ФАРВАТЕРА и работает независимо от веб-запросов. Настройка `GASMETER_ARSHIN_WORKER_INTERVAL_SECONDS` задаёт частоту просмотра очереди, а не интервал повторной сверки конкретного прибора.

Первичное заполнение выполняется по актуальной выгрузке физических СИ: до импорта номеров необходимо проверить их точность и связь с инвентарным источником. Демонстрационные номера не добавлять.
