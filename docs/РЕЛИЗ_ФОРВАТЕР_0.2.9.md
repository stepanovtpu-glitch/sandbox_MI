# ФОРВАТЕР 0.2.9 — исходные сканы методик

**23.11.2026.** Версия 0.2.9 установлена на корпоративном АРХИМЕДе и внешнем стенде. Перед установкой сохранены резервные копии PostgreSQL и предыдущие образы. Оба контура отвечают как ФОРВАТЕР; версия схемы PostgreSQL — 10.

На АРХИМЕД переданы 231 исходный PDF-скан МИ, 224 OCR-текста и 224 файла метаданных распознавания. Все PDF проверены по размерам и SHA-256 из манифеста; 622 из 622 версий МИ привязаны к сканам с сохранением хеша. В «Метрологическом эксперте» найденные фрагменты сопровождаются ссылкой на исходный скан для ручной сверки. Проверка на сервере: 224 OCR-текста, 231 PDF, 622 привязки и хеша, контроль целостности выбранного документа — valid; запрос по диапазону давления дал пять источников, все со ссылками на сканы. Копия библиотеки остаётся на рабочем ПК.

Внешний стенд содержит код и каталог 216 МИ, но не содержит корпоративной выгрузки ТОиР, OCR-корпуса и сканов. Проверка внешней БД: 216 МИ, ноль импортов корпоративной выгрузки и ноль PDF в библиотеке.

Локальные проверки: 159 тестов backend прошли, сборка frontend успешна. Поиск по OCR не является метрологическим заключением; поля требуют сверки с PDF. Ручной разбор 20 методик остаётся открытым. Корпоративная LLM и Яндекс Мессенджер не подключены; доступность ФГИС «Аршин» не подтверждена. Автоматическая доставка нового файла из 1С во входящую папку АРХИМЕДа ещё не настроена.
