# ФОРВАТЕР 0.2.16 — достоверный экран состояния

**23.11.2026.** Исправлен экран настроек: он показывает PostgreSQL на сервере вместо устаревшей подписи о локальной SQLite, указывает на опубликованную выгрузку как источник метрологических данных и показывает пилотный режим. Удалён внутренний путь к OCR-моделям; подпись об авторстве фотографий берётся из единого файла бренда.

После резервного копирования один и тот же архив образов (SHA-256 `c7101c9ae31b1342e860ed71475e03f4fe8807cc588fc5dd870e420bb1a510ae`) установлен на АРХИМЕДе и внешнем стенде. На обоих подтверждены версия 0.2.16, схема PostgreSQL 12 и новая подпись интерфейса. На АРХИМЕДе сохранены 48 312 строк последней выгрузки; на внешнем сервере — 0 корпоративных строк и 0 интеграционных клиентов. Worker бота «Инженерная память» после обновления работает, оставаясь без собственного polling.

На АРХИМЕДе действует ежечасная проверка входящей папки метрологических выгрузок. Следующий новый файл из источника пока не поступил. С сервера не установилось соединение с корпоративной LLM и официальным API ФГИС «Аршин»; расчётные вердикты и локальный поиск не выдают их данные за подтверждённые. Полный сценарий «сообщение пользователя → ответ бота» ждёт реальной входящей команды.

Проверки: 169 тестов backend, TypeScript и производственная сборка frontend, health обоих серверов. Предупреждение сборки о размере основного JS-файла остаётся задачей оптимизации интерфейса.
