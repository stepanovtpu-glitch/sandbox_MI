## Пользовательский сценарий

Раздел метрологического контроля принимает XLSX по проверенному шаблону ИС Метрология, показывает предварительный результат, публикует неизменяемый снимок, ищет точный заводской номер, показывает сроки по плану и позволяет выгрузить выбранный список в CSV. Дата среза и имя файла источника входят в каждую строку CSV. Повторы GUID вынесены в отдельный фильтр и сводку. Сравнение двух снимков показывает добавленные, изменённые, не встретившиеся и неоднозначные строки без автоматического вывода о выбытии прибора.

Бот Яндекс Мессенджера поддерживает локальный поиск `/состояние <номер>` без обращения к Аршину; `/поверка <номер>` выполняет адресный запрос ФГИС. PDF по публичным полям API обозначен как копия сведений, а не официальное свидетельство. Наличие кода бота не означает его запуск на корпоративном сервере: в корпоративном Compose нет polling-worker и доступность ФГИС из этого контура не подтверждена.

## Ограничения следующего этапа

Требуются договор о полном/частичном снимке и мастер-ID с владельцем 1С, автоматическая периодическая доставка файла, очередь решений метролога по конфликтам, контроль свежести, проверенная связь с Аршином и официальный механизм получения документа. Отдельно нужен выбор справочника месторождений/кустов. Эти функции нельзя считать готовыми по текущему релизу.
