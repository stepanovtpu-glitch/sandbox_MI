# ФОРВАТЕР 0.2.19 — достоверный статус базы данных

**23.11.2026.** Исправлена проверка базы на экране готовности расчётного пилота: при PostgreSQL выполняется запрос к действующему соединению, а наличие локального файла SQLite больше не влияет на результат. В системной информации показывается тип серверной базы без строки подключения и учётных данных. Заголовок экрана уточнён, чтобы оценку расчётного пилота не принимали за подтверждение работы внешних интеграций.

Проверки: 173 теста backend, сборка TypeScript/Vite, `git diff --check`. Один архив образов с SHA-256 `9353be04bbcbfd6e4badf5dc8da27d8308499686b98641e6d9cfe8f7d6796f2a` установлен на АРХИМЕДе и внешнем стенде после резервного копирования. На обоих серверах подтверждены версия 0.2.19, PostgreSQL, положительная проверка соединения и ответ `/health`.

**Открытые ограничения.** Сетевой доступ к ФГИС «Аршин» по-прежнему недоступен. Прежний адрес корпоративной LLM остановлен; действующий адрес не предоставлен. Новый файл выгрузки ТОиР и подлинный PDF свидетельства поверки не поступили, поэтому их полный производственный цикл не подтверждён. Оценка готовности относится к расчётному пилоту и не отменяет этих ограничений.
