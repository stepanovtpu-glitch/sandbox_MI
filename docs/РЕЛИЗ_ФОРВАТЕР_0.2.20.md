# ФОРВАТЕР 0.2.20 — дата состояния в ответе бота

**23.11.2026.** Команда `/состояние заводской_номер` в боте «Инженерная память» теперь отдельно показывает плановый срок по выгрузке **на сегодня** и **на дату среза**. В ответе указаны возраст снимка, дата проверки и часовой пояс. При превышении настроенного порога свежести выводится предупреждение; если порог не задан, это прямо сказано. Эти сведения не подтверждают факт поверки в ФГИС «Аршин».

Исправлен способ сборки веб-образа: по умолчанию используется производственная конфигурация nginx с маршрутами `/api/` и `/health`. Скрипт установки на АРХИМЕД проверяет эти маршруты внутри образа до передачи и переключения. Это закрывает обнаруженный при выпуске дефект: первоначальный веб-образ 0.2.20 возвращал HTML вместо ответа API. На АРХИМЕДе прежний исправный веб-образ был сразу восстановлен; после пересборки установлен исправленный архив. Дефектный архив сохранён отдельно для разбора, не используется в релизе.

**Проверки.** 175 тестов backend; сборка TypeScript/Vite; проверка маршрутов nginx в итоговом и в собранном по умолчанию образе. Исправленный архив `forvater-images-fixed.tar` имеет SHA-256 `52855aaa8c6d26b86d90663e9a09fe52ed47056ba038a7506431df8bcaa4bbe7`. После резервного копирования он установлен на АРХИМЕДе и внешнем стенде. На обоих подтверждены HTTP `/health` и версия backend 0.2.20; на АРХИМЕДе bridge бота также показывает 0.2.20. Последний корпоративный снимок содержит 48 312 строк, его возраст на момент проверки — три дня; порог свежести не настроен.

**Границы.** Содержимое ответа команды проверено автоматическими тестами на дату среза и текущую дату. Новое реальное сообщение в чат в этом выпуске не отправлялось; живой маршрут бота был проверен ранее. Сетевой доступ к ФГИС «Аршин» и действующий адрес корпоративной LLM всё ещё отсутствуют. Новый файл периодической выгрузки источником пока не предоставлен.
